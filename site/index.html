02 / GET STARTED

Get started

Linux binary

Download mntui-linux-x86_64 and SHA256SUMS from a release. Place them in the same directory and verify the download before running it.

sha256sum --check SHA256SUMS
chmod +x mntui-linux-x86_64
./mntui-linux-x86_64 --check
./mntui-linux-x86_64 --dry-run

No Python installation required. Builds target x86_64 Linux with glibc (Ubuntu 22.04 baseline); other architectures and musl hosts are not covered. Linux storage utilities are still required.

Run from source

Requires Linux and Python 3.12 or newer. Clone the repository, then install into a virtual environment.

git clone https://github.com/umaxiaotian/mntui.git
cd mntui
python3 -m venv .venv
. .venv/bin/activate
python -m pip install .
mntui --check
mntui --dry-run

System commands

Requires lsblk, blkid, findmnt, mount, and umount. GPT creation uses sfdisk. Formatting uses mkfs.ext4, mkfs.xfs, or mkfs.btrfs. Run mntui --check to see what is missing and installation examples for your distribution.

Viewing devices may work without root. Changes require root; mntui does not invoke sudo itself.

sudo .venv/bin/mntui

Dry-run discovers devices and validates planned changes without modifying storage or fstab. An explicit log file may still be written. Do not interrupt disk writes.

04 / SAFETY

Before you write

Partitioning and formatting permanently destroy data. Back up your data and confirm the target device. Test this early version in a disposable VM before using valuable storage.

  • System disks, read-only devices, and layered LVM, RAID, or encrypted storage are blocked for changes.
  • Partitioning and formatting require separate confirmations. After initialization, return to the disk list to refresh, then select the new partition.
  • Run on the host: device and mount visibility in containers may be incomplete. Avoid concurrent storage operations or fstab edits.
  • Disk operations cannot be rolled back. If mounting succeeds but saving to fstab fails, the filesystem stays mounted. Unmounting does not remove saved fstab entries.
