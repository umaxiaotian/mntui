ディスク管理を、
ターミナルから。

Linuxのディスク確認、パーティションのフォーマット、マウント管理をひとつの画面で。nmtuiとcfdiskに着想を得た、キーボードで操作するツールです。

Linux版をダウンロード ↗ソースコード ↗

$ mntui --dry-run

01 / FEATURES

できること

01

確認する

ディスク、パーティション、ファイルシステム、UUID、マウント先を一覧で確認できます。

02

準備する

未使用のディスクにGPTと全容量のパーティションを作成。通常のパーティションをext4・XFS・Btrfsでフォーマットできます。

03

マウントする

UUIDでマウントし、必要に応じて/etc/fstabに保存。アンマウントにも対応します。

04

事前に確かめる

必要なコマンドの有無を確認し、--dry-runで変更予定を確認できます。

02 / GET STARTED

はじめる

Linuxバイナリ

リリースからmntui-linux-x86_64とSHA256SUMSを同じディレクトリにダウンロードし、検証してから実行します。

sha256sum --check SHA256SUMS
chmod +x mntui-linux-x86_64
./mntui-linux-x86_64 --check
./mntui-linux-x86_64 --dry-run

Pythonのインストールは不要です。対象はglibcを使用するx86_64 Linux（Ubuntu 22.04を基準にビルド）。他のアーキテクチャやmusl環境は対象外です。ストレージ操作用のLinuxコマンドは別途必要です。

ソースから実行

LinuxとPython 3.12以上が必要です。リポジトリを取得して、仮想環境にインストールします。

git clone https://github.com/umaxiaotian/mntui.git
cd mntui
python3 -m venv .venv
. .venv/bin/activate
python -m pip install .
mntui --check
mntui --dry-run

必要なシステムコマンド

lsblk・blkid・findmnt・mount・umountが必要です。GPT作成にはsfdisk、フォーマットにはmkfs.ext4・mkfs.xfs・mkfs.btrfsを使用します。mntui --checkで不足しているコマンドと、ディストリビューションに応じたインストール例を確認できます。

デバイスの閲覧は権限によって一般ユーザーでも可能です。変更にはroot権限が必要です。mntuiが自動でsudoを実行することはありません。

sudo .venv/bin/mntui

ドライランはデバイスの検出と変更内容の検証を行い、ストレージやfstabは変更しません。ログファイルを明示した場合はログを書き込むことがあります。実際のディスク書き込み中は処理を中断しないでください。

04 / SAFETY

書き込みの前に

パーティション作成とフォーマットはデータを完全に消去します。バックアップを取り、対象デバイスを確認してください。開発初期のため、大切なデータを扱う前に使い捨てのVMで試してください。

  • システムディスク、読み取り専用デバイス、LVM・RAID・暗号化ストレージの階層デバイスは変更できません。
  • パーティション作成とフォーマットは、それぞれ確認が必要です。初期化後はディスク一覧に戻って更新し、新しいパーティションを選択してください。
  • コンテナではデバイスやマウント情報が不完全な場合があるため、ホスト上で実行してください。他のツールによる同時操作やfstabの同時編集は避けてください。
  • ディスク操作は元に戻せません。マウント成功後にfstabへの保存が失敗した場合、マウントは維持されます。アンマウントしてもfstabの設定は削除されません。
